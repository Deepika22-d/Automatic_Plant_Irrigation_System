🌱🤖 Smart Crop Disease Detection & Automated Action System

🚜 An AI + IoT Based Smart Agriculture Solution

A real-time plant leaf disease detection and control system that uses deep learning (CNN) to identify diseases and automatically activates pumps or sprayers for treatment — improving crop health and reducing losses.

🌟 Why This Project?

Crop diseases significantly reduce agricultural yields due to delayed detection and manual monitoring.

This project solves that by providing:

✨ AI based disease identification
✨ Automatic pump/sprayer control
✨ Real-time monitoring via IoT
✨ Smart irrigation based on soil moisture
✨ Alerts to farmers remotely

🎯 Project Objective

✔ Early detection of plant leaf diseases
✔ Automated disease control
✔ Monitor environmental conditions
✔ Enable smart irrigation
✔ Increase productivity & sustainability

🛠️ Hardware Components

🔹 ESP32 Board – Main IoT controller with WiFi

🔹 USB Webcam – Captures leaf images

🔹 Soil Moisture Sensor – Detects soil dryness

🔹 DHT11 Sensor – Measures temperature & humidity

🔹 DS3231 RTC Module – Time-stamped data logging

🔹 0.96” OLED Display – Shows system status

🔹 4-Channel Relay Module – Controls pump/sprayer

🔹 Water Pump / Sprayer – Automatic treatment

🔹 Float Sensors – Monitors tank water levels

🔹 5V Adapter / Buck Converter – Power supply

💻 Software & Technologies

🧠 TensorFlow / Keras – CNN Disease Classification
📷 OpenCV – Image Processing
🐍 Python – AI Model Development
🛠 Arduino IDE – ESP32 programming
📲 Blynk / Telegram – IoT notifications

⚙️ Working Process

1️⃣ Leaf image is captured through the webcam

2️⃣ CNN model classifies disease (Wilt / Blight / Rust)

3️⃣ Soil moisture & environmental data are read

4️⃣ If disease detected → Relay activates pump/sprayer

5️⃣ OLED displays system status

6️⃣ Farmer receives real-time alert

7️⃣ All data logged with timestamp
